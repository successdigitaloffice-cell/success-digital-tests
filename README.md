## 🛠️ नवीन दैनंदिन टेस्ट कशी ॲड / अपडेट करावी (How to Add Daily Tests)

1. नवीन टेस्ट फाइल याच फोल्डरमध्ये तयार करा (उदा. `test_02.html` किंवा `tet_paper_1_test_02.html`).
2. [index.html](index.html) मधील `test-list` विभागात नवीन कार्ड ॲड करा आणि फाइलची लिंक द्या.
3. गिटहबवर कमिट आणि पुश करा. गिटहब पेजेस (GitHub Pages) आपोआप लाईव्ह अपडेट होईल!
