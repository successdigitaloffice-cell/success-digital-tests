5. HOW TO SYNC & UPDATE TESTS DAILY (1-CLICK AUTOMATION)
--------------------------------------------------------------------------------
कोणताही नवीन प्रश्न किंवा फाइल बदलल्यानंतर:
पद्धत १: "upload_daily_test.bat" या फाइलवर फक्त डबल-क्लिक (Double-Click) करा.
पद्धत २: पॉवरशेलमधून कमांड चालवा:
         powershell -NoProfile -ExecutionPolicy Bypass -File "upload_daily_test.ps1"

ही स्क्रिप्ट बदललेल्या फाइल्स शोधून GitHub REST API द्वारे आपोआप अपलोड करते आणि अवघ्या काही सेकंदांत GitHub Pages वर सर्व चाचण्या लाईव्ह अपडेट होतात!
